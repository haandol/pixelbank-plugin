<h1 align="center">PixelbankStudio Plugin</h1>

<p align="center"><a href="README.md">English</a> · <strong>한국어</strong></p>

Codex나 Claude Code에서 PixelbankStudio를 사용하고, 시각적인 선택과 레이어 배치는 웹 편집기에서 이어가세요. 기존 PixelbankStudio 계정으로 브라우저에서 로그인합니다. 비밀번호·토큰·AWS 키를 대화에 복사할 필요가 없습니다.

간단한 소개와 실제 결과 예시는 [저장소 개요](https://github.com/haandol/pixelbank-plugin/blob/main/README.ko.md#사용-예시)를 확인하세요. 이 가이드는 입력 조건, 워크플로 이어가기와 연결 복구를 설명합니다.

## 설치와 연결

macOS 또는 Linux의 Bun 1.4.2 이상이 필요합니다. 패키지의 `dist/` 번들에 실행 의존성이 포함돼 있어 사용자에게 필요한 것은 Bun 실행 환경과 플러그인 패키지입니다.

### Bun이 없다면 먼저 설치하세요

설치된 버전을 확인합니다.

```sh
bun --version
```

Bun이 없거나 1.4.2보다 오래된 버전이라면 [공식 설치 프로그램](https://bun.sh/docs/installation)으로 검증된 버전을 설치하세요.

```sh
curl -fsSL https://bun.sh/install | bash -s "bun-v1.4.2"
```

Linux에서 설치하려면 `unzip`이 필요합니다. 새 터미널에서 `bun --version`을 다시 확인한 뒤, Codex나 Claude Code를 재시작해 Bun을 찾을 수 있게 합니다.

어시스턴트가 계속 Bun을 찾지 못하면 새 터미널에서 `command -v bun`을 확인하고 그 터미널에서 CLI 호스트를 실행하세요. MCP 서버를 수동으로 설정하는 경우에는 해당 실행 파일의 절대 경로를 명령으로 지정할 수 있습니다.

### 플러그인 설치

Codex:

```sh
codex plugin marketplace add haandol/pixelbank-plugin
codex plugin add pixelbank@pixelbank
```

Claude Code 안에서는 다음 명령을 사용합니다.

```text
/plugin marketplace add haandol/pixelbank-plugin
/plugin install pixelbank@pixelbank
```

로컬 체크아웃을 설치하려면 `haandol/pixelbank-plugin` 대신 저장소 루트의 절대 경로를 사용하세요. 패키지 하위 디렉터리를 지정하지 않습니다.

설치 후 설정 스킬을 실행하거나 “내 PixelbankStudio 계정을 연결해 줘”라고 요청하고 브라우저에서 로그인하세요. 콜백 주소는 `http://localhost:18766/oauth/callback`, 원격 MCP 리소스는 `https://api.pixelbankstudio.com/mcp`입니다. 서버 URL만 등록하는 방식은 이 플러그인의 연결 절차가 아닙니다.

계정 연결 승인은 제공되는 계정 작업을 허용합니다. 크레딧 사용과 자산 삭제에는 각각의 승인 규칙이 적용됩니다. “PixelbankStudio 연결을 해제해 줘”라고 요청하면 연결을 취소하고 로컬 인증 정보를 정리합니다. 정리가 대기 중이라면 안내된 복구 절차를 완료한 뒤 연결 해제 여부를 판단하세요.

## 만들고 웹 편집기로 이어가기

현재 사용 가능한 도구와 입력 형식은 인증된 서버가 제공하는 목록을 기준으로 합니다. 패키지의 [도구 계약](contracts/tools.json)에서 전체 요청 형식을 확인할 수 있지만, 이 파일은 인터페이스의 스냅샷입니다. 실제 제공 여부는 연결된 서버가 결정합니다.

| 작업 | 사용 방법 |
| --- | --- |
| 이미지 준비·재사용 | 선택한 로컬 PNG·JPEG·WebP를 올리고, 소유한 자산과 미리보기·원본 다운로드를 확인합니다. 입력을 저장하고 선택한 자산의 메타데이터를 관리할 수 있습니다. |
| 지정한 이미지 처리 | 배경 제거, 입력이 완성된 분할·이미지 생성, 확대 견적과 제출을 요청하고 저장 결과나 작업 상태를 확인합니다. |
| 여러 단계 이어가기 | 저장된 워크플로를 시작해 입력을 연결하고, 지원하는 단계를 수행한 뒤 결과를 선택합니다. 서버가 확인한 워크플로 버전으로 다음 작업을 이어갑니다. |
| 애니메이션·시각적 편집 | 애니메이션을 생성·조회하고 프레임을 재조합하거나 수정합니다. 웹에서 편집할 분할·이미지 생성 작업공간도 준비할 수 있습니다. |

현재 버전은 이미지·애니메이션과 관련 워크플로를 지원합니다. 공간·프리비주얼라이제이션·영상 가져오기·영상 생성 실행은 MCP에서 제공하지 않습니다.

예를 들어 다음처럼 요청할 수 있습니다.

> 이 제품 사진으로 홍보 배너를 만들어 줘. 배경을 지우고 문구를 넣을 공간을 마련한 다음, PixelbankStudio에서 레이어를 조정할 수 있게 열어 줘.

어시스턴트는 선택한 파일만 올리고 현재 가격과 무료 사용 횟수를 확인한 뒤 워크플로를 시작합니다. 원본 이미지·지원하는 레이어 설정·프롬프트 초안을 담은 소유자 전용 웹 링크를 준비합니다. 링크를 열면 이미지 처리나 크레딧 차감 없이 설정이 불러와집니다. 편집하려면 같은 PixelbankStudio 계정으로 로그인하세요.

웹 편집을 마친 뒤 워크플로에서 결과를 선택하고 계속 진행해 달라고 요청하세요. 어시스턴트는 같은 워크플로와 허용된 다음 작업을 확인합니다. 탭을 열거나 닫는 것만으로 단계가 완료되지는 않으며, 최종 수락은 사용자가 명시적으로 결정합니다.

워크플로를 떠나도 진행 상태는 저장됩니다. 같은 실행으로 돌아와 계속 진행하거나, 완료한 실행을 다시 열어 결과를 수정할 수 있습니다.

준비된 작업공간은 계정 삭제 때까지 보관되는 변경 불가능한 초기 설정입니다. 다시 열면 그 초기 설정을 복원하며, 이후 캔버스 편집 내용은 자동 저장되지 않습니다. 새 작업공간을 준비할 때는 새 작업 키를 사용합니다. 오래된 워크플로 버전, 누락된 이미지, 관련 없는 미저장 작업과의 충돌은 복구 안내와 함께 거부됩니다. 이미지 생성에서는 합성용 레이어 외에 이름이 있는 객체 참조를 최대 5개까지 사용할 수 있으며, 현재 0도가 아닌 레이어 회전은 지원하지 않습니다.

## 인증과 작업 안전

원격 전송은 MCP `2026-07-28`과 `2025-11-25`를 지원합니다. HTTP 인증은 OAuth 2.1의 Authorization Code와 PKCE S256을 사용합니다. 전용 공개 Cognito 클라이언트, 리소스에 연결된 액세스 토큰과 명시적인 읽기·쓰기·실행 권한을 사용하며, 웹과 MCP 인증 정보의 권한은 분리됩니다.

인증 정보는 `~/.pixelbank-plugin/`의 소유자만 접근할 수 있는 파일에 저장되며 서버·기기·호스트 프로필별로 분리됩니다. Codex와 Claude는 별도 프로필을 사용합니다. 토큰 갱신은 동시에 실행되지 않도록 직렬화되고 갱신 토큰은 교체됩니다. 최초 로그인에서 1일을 넘겨 권한을 연장할 수 없습니다. 인증 파일을 다른 기기로 복사하거나, 정리 대기 상태를 우회하려고 삭제하지 마세요.

과금되는 요청에는 승인된 최대 크레딧과 하나의 고정된 작업 키가 포함됩니다. 재시도할 때는 이 두 값과 원래 요청을 유지합니다. 결과가 불확실한 쓰기 작업은 자동 재전송하지 않습니다. 접수된 작업은 서버가 완료·실패를 확인할 때까지 접수 상태로 안내합니다. 견적 조회와 준비된 작업공간 열기는 무료 횟수나 크레딧을 사용하지 않습니다.

로컬 브리지는 `pixelbank_connect`, `pixelbank_disconnect`, `pixelbank_upload_image`, `pixelbank_open_workspace`, `pixelbank_open_credits_page`의 다섯 도구를 제공합니다. 나머지는 인증된 서버에서 제공됩니다. 제공사 인증 정보·계정 관리·결제 기능은 노출하지 않습니다. 페이지는 기본 브라우저에서 열며 사용자의 활성 탭을 자동 조작하지 않습니다.

요청한 작업에 필요한 크레딧이 부족하면 브리지가 [크레딧 구매 페이지](https://www.pixelbankstudio.com/pricing)를 자동으로 열고 링크를 반환합니다. 브라우저가 열리지 않으면 같은 링크를 사용하세요. 웹사이트에서 상품을 선택하고 결제한 뒤 원래 요청을 계속해 달라고 하면, 어시스턴트가 바뀐 잔액·가격·승인을 확인해 진행합니다. 사용할 수 있는 무료 횟수가 있으면 잔액 0이어도 작업을 수행할 수 있습니다. 페이지 열기로 크레딧이 추가되거나 처리가 자동 재전송되지는 않습니다.

이미지 조회에서 `ASSET_NOT_FOUND`가 반환되면 라이브러리를 새로 고치거나 사용 가능한 이미지를 선택해 계속 진행하세요. 저장된 이미지가 없는 경우를 일시적인 서비스 장애와 구분해 안내합니다.
