- `generate-and-cutout.jpg` (Korean: `generate-and-cutout.ko.jpg`) pairs the generated robot with the actual background-removal result. The checkerboard indicates transparency; the panels were resized and labeled for the README.
- `robot-wave.gif` is the generated 16-frame animation of the original blue-background image. It retains its original dimensions and frames.
- `frame-edit.jpg` (Korean: `frame-edit.ko.jpg`) compares the actual first frame before and after a single-frame correction. Only that frame was replaced in the test.
- `studio-editor.jpg` (Korean: `studio-editor.ko.jpg`) is a screenshot of the local PixelbankStudio web editor with the test image loaded. It is cropped to the editor so account information is excluded. The visible draft instruction was not submitted.

Static previews are compressed for the README. No private service code, credentials, account details or execution logs are included.
