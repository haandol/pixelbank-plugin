# README 미디어

[English](README.md) · **한국어**

이 이미지들은 실제 이미지·애니메이션 처리를 수행한 PixelbankStudio MCP 테스트에서 얻었습니다. 고객 업로드가 아닌 테스트용 합성 예시입니다.

- `generate-and-cutout.jpg`와 한국어판 `generate-and-cutout.ko.jpg`는 생성된 로봇과 실제 배경 제거 결과를 함께 보여줍니다. 체크 무늬는 투명 영역이며, README에 맞춰 크기를 조정하고 라벨을 붙였습니다.
- `robot-wave.gif`는 하늘색 배경의 원본 이미지로 생성한 16프레임 애니메이션입니다. 원래 크기와 프레임을 유지합니다.
- `frame-edit.jpg`와 한국어판 `frame-edit.ko.jpg`는 한 프레임 수정 전후의 실제 결과를 비교합니다. 테스트에서는 해당 프레임만 교체됐습니다.
- `studio-editor.jpg`와 한국어판 `studio-editor.ko.jpg`는 테스트 이미지를 불러온 로컬 웹 편집기 화면입니다. 계정 정보가 보이지 않도록 편집기 영역만 캡처했습니다. 표시된 프롬프트 초안은 실행하지 않았습니다.

정적 미리보기는 README에 맞춰 압축했습니다. 비공개 서비스 코드·인증 정보·계정 정보·실행 로그는 포함하지 않습니다.
