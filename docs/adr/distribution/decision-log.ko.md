# 결정 변경 이력: distribution

[English](decision-log.md)

독립 배포 패키지의 주요 결정 변경을 최신순으로 기록한다. 현재 유효한 요구사항과 근거는 해당 ADR에 함께 보존한다.

## 2026-11-12 — 자동 산출물 동기화를 별도 작업으로 연기

- **Current ADR**: [Bun 기반 플러그인 설치와 배포](./0001-bun-plugin-runtime.md)
- **Change type**: 요구사항 규칙 변경
- **What**: 실시간 입력 검증과 제한된 대기는 유지하고 자동 내보내기·저장소 동기화는 이번 구현에서 제외한다.
- **Why**: 사용자가 워크플로의 배포 준비를 먼저 마무리하고 자동 내보내기는 ADR만 남기기로 했다.

## 2026-11-12 — 실시간 계약 검증과 제한된 워크플로 대기

- **Current ADR**: [Bun 기반 플러그인 설치와 배포](./0001-bun-plugin-runtime.md)
- **Change type**: 아키텍처와 요구사항 규칙 변경
- **What**: 원격 호출 전달에 최신 목록 기반 입력 검증, 공개 계약 동기화와 읽기 전용 워크플로 대기를 추가한다. 기존 Bun 설치와 발행 경계는 유지한다.
- **Why**: API 변경마다 별도 스키마를 손으로 고치지 않고 입력을 맞추며, 오래 실행되는 작업을 다시 제출하지 않고 진행 상황을 확인하기 위해서다.
